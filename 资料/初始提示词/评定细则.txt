基于你提供的五维评定细则和“逐项提交证明材料（文字必填、图片可选）”的需求，我规划了一个清晰、可扩展的 Web 页面布局。整体采用**折叠面板 + 动态表单**结构，让每个评定部分既能独立分块，又能在统一页面中完成所有材料提交。

#### 2. 拓展评定区块
结构与基础评定类似，对于**荣誉、履职、好人好事**等，也采用“添加条目”的方式，每条上传对应证明。

```
┌─ 拓展评定（上限36分，占20%） ────────────────────┐
│  ■ 1. 德育类荣誉（国家级30分→院级5分，上限30） │
│    ＋ 添加荣誉                                    │
│    ┌ 荣誉 #1 ──────────────────────────┐          │
│    │ 荣誉级别：[下拉选择：国家级/省部...]│          │
│    │ 荣誉名称：优秀志愿者               │          │
│    │ 文字说明：...                      │          │
│    │ 图片(可选)：[证书照片]             │          │
│    └──────────────────────────────────┘          │
│  ■ 2. 学生组织履职（优秀20/称职10，上限20）     │
│    选择评价：[优秀▼]  文字说明 [图片]            │
│  ■ 3. 好人好事/见义勇为（+20分）                │
│    文字说明 + 图片                               │
│  ■ 4. 发表德育类文章/作品（+10分）              │
│    文字说明（标题、刊物等）+ 图片（截图）        │
└──────────────────────────────────────────────────┘
```

其余四个评定部分（学术、体育、美学、劳动）完全采用**相同的布局模式**，只是内部的子项名称和计分规则不同。例如：
- **学术科技创新**：学科竞赛/大创结题（一次性25分）、科技活动（多次添加）、讲座报告（多次添加）等。
- **劳动与社会实践**：劳动时长、志愿时长、社会实践、宿舍卫生等，其中劳动/志愿时长可用数字输入，并自动计算超出部分的额外加分。

### 证明材料组件的统一设计
所有项目的证明材料区域均包含：
1. **文字说明文本框**（必填，placeholder动态变化，如“请描述参加该活动的情况…”）。
2. **图片上传区**（非必填，支持拖拽/点击上传，可预览缩略图，限制单张或多张，旁边有“可选”标记）。
3. 对于可重复添加的条目，额外提供 **“＋添加”按钮**，每一条都有独立的证明材料组。
4. 扣分或负面项（如违规、处分）会预设勾选框或简短输入，但仍保留证明材料通道以用于申诉。

### 交互与状态细节
- **折叠面板**默认展开第一个“道德与思想素质”，其余折叠，用户可逐个填写。
- 每个评定部分的标题右侧实时显示**当前累计得分**（根据填写的次数、选择的级别粗略计算，最终以审核为准）。
- **图片上传**为独立可选操作，不选择图片也能保存文字说明。所有材料支持暂存，避免丢失。
- 底部固定“临时保存”和“提交全部材料”按钮，提交前校验必填的文字说明是否已填写。

这个布局将规则中的每一项都落地为具体的填报入口，分块清晰、操作一致，既满足了逐项证明的需求，又通过动态列表容纳了多次累积的计分项目。
