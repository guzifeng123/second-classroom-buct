# RN Smoke Checklist

## 目标

用于 RN Android Bundle 通过后的人工 smoke 验收，补齐“构建产物存在”之外的基本视觉与交互确认。

## 前置条件

- 已执行 `npm.cmd run build:rn`，并确认 `dist/rn/android/index.bundle` 存在且非空。
- Android 真机或模拟器可启动应用。
- 可使用离线演示模式；若配置了后端接口，也需要记录 API 与 WebSocket 状态。

## 验收流程

| 步骤 | 页面或流程 | 操作 | 通过标准 |
| --- | --- | --- | --- |
| 1 | 登录页 | 启动应用，输入测试学号并登录。 | 登录页无白屏、无明显布局重叠，能进入评定页；API、WebSocket 和离线模式状态文案可读。 |
| 2 | 评定页首页 | 查看顶部状态栏、评分概览、填报入口和底部操作。 | 五维评分、材料数量、同步状态和主要操作不遮挡；页面可纵向滚动。 |
| 3 | 评定页填报 | 选择一个维度条目，填写文字、选择选项或数值，添加一条记录。 | 输入框、选项、数值输入和添加记录可操作；记录分数更新；本地未保存/已保存状态变化可见。 |
| 4 | 图片上传区域 | 在证明记录中打开图片上传、图片库和图文库入口。 | 按钮尺寸可点，图片区域不溢出；无权限或无数据时有明确提示；失败图片定位高亮不遮挡操作。 |
| 5 | 图文材料列表页 | 从评定记录的图文入口打开图文材料列表页，搜索或选择已有材料。 | 列表、搜索、空态和错误兜底可读；选择材料后能返回评定条目引用。 |
| 6 | 图文编辑页 | 新建或继续编辑一条含文字和图片的图文材料，保存后返回引用。 | 标题、文字块、图片块、预览和保存可操作；保存失败不丢失当前编辑内容。 |
| 7 | 图文快照页 | 从引用卡片或提交结果打开图文快照页。 | 图文快照页内容可读，图片占位不撑破页面，返回按钮可用。 |
| 8 | 图片库页 | 打开图片库页，切换来源、维度、引用状态和排序筛选。 | 筛选控件可操作，空态或图片网格可读，重置筛选有效。 |
| 9 | 提交前预览页 | 从评定页进入提交前预览页，查看问题列表和材料明细。 | 分数、材料数量、待完善数量准确显示；点击待完善问题可返回对应条目。 |
| 10 | 提交结果页 | 在具备可提交条件时提交；离线时触发提交拦截。 | 成功时进入提交结果页；离线或失败时弹窗说明清晰，草稿仍保留。 |
| 11 | 提交历史页 | 打开提交历史页，查看审核状态、退回原因和补充入口。 | 状态标签、审核意见、退回原因和“去补充”入口可读可点。 |
| 12 | 状态说明页 | 通过无效入口、离线不可用或同步异常场景进入状态说明页。 | 页面能说明当前状态和下一步操作，返回入口可用，文案不会让用户误以为已正式提交。 |

## 视觉检查

- RN 样式不应出现 H5 专用媒体查询导致的红屏或样式解析错误。
- 主要按钮高度、文字和点击区域在 Android 上不应互相遮挡。
- 评定页、图片库、预览页和结果页的横向内容不应明显溢出屏幕。
- 图片缩略图、占位图和失败高亮应保持固定尺寸，不能挤压相邻操作。
- 图文快照页的图片区域、占位文案和返回按钮应保持在屏幕内，不出现横向溢出。

## 记录格式

可先生成记录模板，再按实际结果补全；模板的步骤结果表会包含 `shell`、`detail`、`status`、`flow` 类型列，便于后续自动化 smoke 按页面类型回填截图和日志：

```bash
npm.cmd run smoke:rn:record -- --out output/smoke/rn-smoke-2026-07-11.md
```

自动化 smoke 可以先输出结果 JSON，再生成已回填的记录：

```bash
npm.cmd run smoke:rn:results -- --out output/smoke/rn-results.json
npm.cmd run smoke:rn:finalize -- --results output/smoke/rn-results.json --out output/smoke/rn-smoke-2026-07-11.md
```

`smoke:rn:finalize` 会先执行 `validate:smoke-results`，校验步骤数量、顺序、`flow` 和 checklist 一致，`type` 与页面矩阵一致，`result` 只能为 `未执行`、`通过`、`失败` 或 `跳过`，截图和日志使用项目内相对路径，再生成记录。

```json
{
  "steps": [
    {
      "flow": "登录页",
      "result": "通过",
      "note": "启动和登录入口正常",
      "screenshot": "output/smoke/rn-login.png",
      "log": "output/smoke/rn-login.log"
    }
  ]
}
```
